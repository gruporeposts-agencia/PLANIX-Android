# PLANIX Android

Aplicación local PLANIX para Android.

## Compilar desde GitHub
Cada cambio en `main` ejecuta **Compilar PLANIX APK**. Al terminar, abre **Actions**, entra en la ejecución más reciente y descarga el artefacto **PLANIX-APK**. Dentro encontrarás `PLANIX.apk`.

- Funciona localmente y sin hosting.
- Los agendamientos se almacenan en IndexedDB dentro de la app.
- Incluye exportación y restauración de respaldos JSON.
- Identificador de aplicación: `com.planix.local`.
